# Pathways to a Billion-Death Year

Existing climate-impact models do not yield a defensible probability of one
billion excess deaths in a rolling year. This paper specifies the missing model
class: a stochastic, multilayer system in which climate hazards deplete buffers,
cross food and infrastructure networks, alter political responses, and reach
mortality through competing risks. Its purpose is to make an extreme claim
testable without pretending that it has already been estimated.

## Build

```bash
uv run build.py          # -> paper/PAPER.pdf  (vendored canonical recipe)
```

Requires `pandoc` and `xelatex` on PATH. From the workspace you can also run
`papers build climate-triggered-global-cascades`.

Part of [piatra-papers](https://github.com/piatra-institute). See the workspace
